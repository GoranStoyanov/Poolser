# Poolser 1.4

## Mac

- Save and name multiple wallets, switch between them, or see combined totals and positions in All Wallets. Choose what the menu bar shows.
- Add a small or medium portfolio widget and set it to one wallet or all wallets.
- See price ranges, daily fees and realized returns directly on redesigned position cards; open Details for holdings and pool statistics.
- Keep the last successful portfolio visible through connection outages, including an offline restart. Poolser refreshes when the connection returns.
- Review collection details more comfortably in narrow browser windows.

## iPhone and iPad — first release

- Monitor Uniswap v3 and v4 positions, daily fees and range attention across saved wallets.
- Swipe between wallets or view their combined portfolio; use pull to refresh and native position Details.
- Add small and medium widgets for one wallet or all wallets.

Fee collection remains a Mac feature. Both apps require your own Infura API key and a public wallet address.
